# CNC Editor 2D — iOS

Native SwiftUI port of the Android app (com.cnceditor.app). Bundle ID: `com.aries-rst.cnceditor.app`.
Built with XcodeGen + GitHub Actions (see `.github/workflows/build.yml`).
Polygon clipping/offset: Clipper 6.4.2 by Angus Johnson (Boost Software License) via a small C bridge.
