# CNC Editor 2D — 使用者指南

用於為數控雕刻機準備二維加工任務的應用：繪製或開啟向量，計算刀具路徑，併為你的機床儲存加工程式。
- **Weihong / NcStudio**：**.tap** 檔案，單主軸。
- **Superstar（4 主軸）**：**.nc** 檔案。刀具號即主軸號。

## 1. 入門

### 開始介面
- **新建模型**：設定板材尺寸。
- **開啟模型**：DXF、SVG、G 程式碼（.tap / .nc）或 .cnc2d 專案。
- **從圖片／照片建模**：相機照片或相簿圖片作為底圖。
- **返回模型**：已有開啟的模型時顯示。
- 頂部為 **語言** 選擇（🌐，17 種語言）。下方為 **使用者指南**、**高階版**，以及 ARESTI Labs 其他應用和網站的連結。

### 新模型尺寸
- **寬度（X）** 和 **高度（Y）**：毛坯尺寸。按鈕 1830×2750、2070×2800、1220×2440、2050×3050 可填入標準板材。
- **模型原點**：點選示意圖的某個角或中心。這就是機床的 X0 Y0，通常為左下角。
- **單位**：毫米或英寸。內部一律以毫米儲存。
- **材料厚度**：用於刀具路徑的深度。

## 2. 編輯介面

- **選單欄**（頂部）：🏠 返回開始介面，然後是 檔案、編輯、模型、向量、刀具路徑、幫助。帶 ▸ 的專案開啟子選單，“← 返回” 回到上一級。
- **檢視欄**（選單下方）：
  - ☰ — 顯示或隱藏左側面板；
  - 縮放至模型、放大、縮小、網格；
  - 撤銷、重做；
  - **選擇**、**節點**、**新增到選擇**；
  - ⟳ 螢幕方向：橫屏 → 豎屏 → 自動旋轉；
  - **選擇 ▾** 選單，⋮ 操作選單；
  - “已選：N” 計數。
- **面板**有三個標籤（豎屏在底部，橫屏在左側）：
  - **專案**：資訊、圖層、選擇提示、底圖；
  - **助手**：所有繪圖和編輯工具。開啟某個工具時，其引數顯示在這裡；
  - **刀具路徑**：路徑列表、材料、刀具庫、計算和儲存程式。
- **圖紙**：白色矩形就是毛坯。原點處的紅色和綠色短線是 X 軸和 Y 軸。
- 圖紙底部的 **提示** 告訴你現在該做什麼。需要取點時會有 “取消” 按鈕。

長按任意圖示可顯示其名稱。角上帶 ◢ 的圖示是一個工具組：點選會開啟其中的工具列表。最後選用的工具會留在按鈕上。

## 3. 圖紙上的手勢

- **單指點選向量**：選中它。
- **拖動已選向量**：移動。
- **選框角上的方形手柄**：等比縮放。
- **選框上方的圓形手柄**：以 1° 步進旋轉。
- **在空白處拖動**：選擇框。
  - **從左到右**（藍色實線）：選中完全位於框內的向量。
  - **從右到左**（綠色虛線）：選中與框接觸的所有向量。
- **點選空白處**：取消選擇。
- **雙指**：平移和縮放（捏合）。
- **長按向量**：開啟多選。
  - 之後每次點選都會把向量加入或移出選擇。
  - 粉色圓圈中的數字表示選擇順序。順序很重要：對齊以最後選中的為基準，相減時減去最後一個。
- **有選中物件時長按空白處** 會開啟操作選單。

選中的向量以帶光暈的粗粉色線顯示，封閉向量還會被淺色填充。

## 4. 選擇多個向量（代替 Shift 鍵）

- 檢視欄上的 **新增到選擇** 按鈕：開啟時，每次點選都會新增或移除向量。選擇框也會新增到已有選擇中。
- **長按向量** 會臨時開啟同樣的模式。用 “新增到選擇” 或 “取消選擇” 關閉。
- **選擇 ▾** 選單：
  - 全部；
  - 當前圖層全部；
  - 僅封閉、僅開放；
  - 相似尺寸（與第一個選中的樣本相似）；
  - 反向選擇；
  - 取消選擇；
  - 已選列表。
- **已選列表**（或點選 “已選：N”）：按順序列出向量及其尺寸。✕ 將向量移出選擇。

## 5. 繪製圖形

**助手** 標籤 → “向量工具”。每種圖形都有兩種畫法：
- **用手指**：在圖紙上拖動。面板欄位立即顯示尺寸。
- **用數值**：輸入中心、寬度、高度、半徑等，然後按 “建立／完成”。

圖形剛畫好時，修改任何欄位都會在圖紙上同步改變。“完成” 確定圖形。“點選定中心” 可以點選指定中心。

- **矩形**：寬度、高度、圓角半徑；圓角或反圓角（內凹）。
- **圓**：中心和半徑或直徑。
- **橢圓**：中心、寬度、高度、旋轉角。
- **多邊形**：邊數、半徑、旋轉。
- **星形**：角數、外半徑和內半徑。
- **圓弧**，三種方式：三點；中心、起點和終點；起點、終點和半徑。
- **多段線**：點選圖紙，每次點選新增一個點。下一個點也可以用數值輸入。“閉合” 連線到第一個點。

要 **編輯已完成的圖形**：選中它，然後 ⋮ → “編輯圖形／文字…”。

## 6. 節點

**節點** 按鈕：選中向量並拖動它的點。
- 藍色方塊是點，綠色是起點，圓圈是貝塞爾控制點。
- **長按點**：刪除點、平滑、設為起點、輸入座標。
- **長按線段**：
  - 轉換為直線、圓弧或貝塞爾曲線；
  - 插入點；
  - 插入起點；
  - 刪除線段（剪斷向量）。

## 7. 編輯向量

所有命令都在 **向量** 選單和助手中的 “定位、合併、修剪” 部分。
- **變換**：精確移動、尺寸（保持比例）、旋轉、傾斜，可帶或不帶複製。
- **映象**：水平或垂直，相對自身中心或圖紙。
- **偏移**：向外或向內偏移指定距離；尖角或圓角。
- **陣列複製**：按行列，指定間隙或間距。**環形**：圍繞中心 N 個副本。
- **對齊**：相對最後選中的物件按邊和中心對齊；“圖紙中心” — 相對毛坯。
- **組合／取消組合**：組作為一個整體被選擇和移動。
- **合併封閉向量**：
  - 焊接（相加）；
  - 相交；
  - 相減（從其他物件中減去最後選中的）；
  - 排除公共部分。
- **閉合**：用直線、曲線或移動端點閉合。**連線兩個開放向量**：用直線、曲線或移動端點。**重合點**：在公差範圍內把許多碎片連成鏈。
- **向量醫生**：查詢重合點、自相交和環並修復。
- **曲線轉圓弧**：用圓弧和直線替換貝塞爾曲線（程式行更少，切削更平滑）。
- **倒圓角**：點選一個角並設定半徑。這裡還可以把兩個向量延伸到交點。
- **剪刀（修剪）**：點選線段即刪除它在交點之間的部分。
- **裁剪**：保留所選輪廓內部或外部的向量。
- **切分**：用沿 X 或 Y 方向的直線切開向量。
- **外框**：在所選物件周圍生成帶邊距的矩形。
- **轉換**：在向量中識別圓或矩形並轉為 “圖形”。
- **反轉方向**：對加工順序和加工側很重要。
- **鎖定**：防止向量被誤移動。
- **屬性**：尺寸、長度、面積、點數、直線、圓弧和曲線數量。

## 8. 文字

**向量文字**：
- 字型：類 Arial、類 Times、類 Courier、DejaVu 或單線體（用於單線雕刻）；
- 高度、粗體、斜體；
- 對齊、字距和行距、字偶間距；
- 拉伸、傾斜、旋轉；
- X/Y 位置。

“建立” 將文字新增到圖紙。之後可以選中並透過 ⋮ → “編輯圖形／文字” 修改。

**沿曲線文字**：選中一條曲線或圓，開啟 “沿曲線文字”，設定在曲線上的起點、與曲線的距離和方向。字母會沿曲線轉動。

## 9. 封套與 “沿曲線貼上”

- **封套**：選中圖案，開啟 “封套”。圖案周圍出現帶節點的框。拖動角點和邊的中點；或者按 “上曲線…”／“下曲線…” 並點選已有曲線（如圓弧），讓框貼合其形狀。“應用” 使圖案變形。這樣可以把花紋放進拱形、波浪形等。
- **沿曲線貼上**：所選圖案的副本沿曲線均勻分佈 — 按數量或按步距，可選擇是否沿曲線旋轉。

## 10. 銘牌與排料

- **批次銘牌**：銘牌模板（輪廓 + 文字）在圖紙上重複，並依次替換文字檔案中的各行。例如門牌號或姓名：一行 — 一塊銘牌。
- **排料**：所選零件按設定尺寸排放到板材上，帶間隙和邊距。可允許旋轉。孔會自動跟隨所屬零件。

## 11. 圖片和照片

- **檔案 → 匯入圖片／照片** 選單或 “圖片” 圖示。來源 — **相簿** 或 **相機**。圖片成為半透明的 **底圖**。
- **底圖設定**：不透明度、可見性、鎖定。尺寸可用數值設定，或 **透過兩點**：點選兩個已知距離的點並輸入實際距離。
- **手動描圖**：在底圖上用多段線和圖形繪製。
- **向量化**（“向量化” 圖示）：
  1. 選擇模式：黑白（按閾值得到剪影）或輪廓。
  2. 設定亮度閾值（或 “自動”）、平滑、去除雜點、反相。
  3. “預覽” 在圖片上顯示將要生成的向量。
  4. “建立向量” 將其加入模型。
- **透視校正**：如果板材是斜著拍的，點選照片上的四個角並輸入實際尺寸，照片就會變正併成為 1:1 比例。
- **鏤空連線橋**：小連線，使字母和圖形的內部部分不會掉落。

## 12. 刀具路徑（加工）

流程：
1. **材料**（刀具路徑標籤 → 材料圖示）：厚度、安全高度 Z、原點位置（加工結束時機床返回的點）。
2. **刀具庫**：刀具編號、直徑、角度（V 形刀）、切深和步距、主軸轉速、進給速度和下刀速度。進給單位為 mm/s 或 mm/min。可以新增、複製、編輯和刪除刀具；刀具庫儲存在手機上。
3. 在圖紙上 **選擇向量**，然後按加工型別。

### 加工型別
- **輪廓**：在輪廓外側或內側（考慮刀具半徑）或沿線切割。設定：
  - 起始和最終深度；
  - 餘量；
  - 方向（順銑或逆銑）；
  - 加工順序。
- **連線橋（Tabs）**：切割時零件不會脫落。自動放置（按數量或間距）或在輪廓上點選手動放置。可設定長度和高度。
- **斜坡下刀**：刀具傾斜進入材料而非垂直 — 負載更小、痕跡更少。
- **沿向量加工**：刀具沿線正中行走。用於雕刻、開槽、單線文字。
- **區域清除**：輪廓內挖槽。偏移走刀（沿輪廓）或光柵（之字形），可設重疊量。
- **V 形雕刻**：使用 V 形刀，深度隨線條寬度變化，形成 “雕刻感” 的文字和花紋。
- **鑽孔**：在圓心處鑽孔，支援啄鑽（啄鑽步距）。

在 “刀具” 部分按 **選擇…** 從刀具庫選擇刀具。按 **計算** 生成刀具路徑，下方顯示切削長度、下刀次數和預計時間。

刀具路徑列表：
- 點選選中路徑及其向量；
- 勾選 — 顯示或隱藏；
- “編輯…” — 開啟引數；
- “重新計算” — 修改向量後使用；
- “刪除”。

### 模擬
“模擬” 圖示：俯視顯示刀具在材料中的走刀過程。播放／暫停、速度、“結果”（一次顯示全部）、“從頭開始”。便於檢查連線橋、內角和間隙。

### 儲存加工程式
**刀具路徑 → 刀具路徑另存為…**：
1. 勾選需要的刀具路徑。
2. 選擇後處理器：
   - **Weihong（.tap）**：用於 NcStudio；
   - **Superstar（.nc）**：4 主軸；刀具號 1–4 = 主軸號；
   - **自定義 .con**：“載入自定義 .con…” — 你的機床後處理檔案（ArtCAM 格式），會被記住。
3. 設定檔名。“預覽” 顯示程式開頭。“儲存” — 選擇資料夾（例如 U 盤或用於傳到機床的資料夾）。

**免費版：** 每天可儲存 1 個加工程式。**高階版**（一次購買，永久有效）取消限制和廣告。

**提示：** 第一次切割前，請在機床上檢查零點和 Z。先抬高 Z “空走” 一遍程式。

## 13. 儲存和匯出

- **儲存（DXF）**：標準 DXF R12，可在任何 CAD/CAM 程式中開啟。其中隱藏儲存了整個專案：圖層、刀具路徑、刀具、底圖。在本應用中開啟這樣的 DXF 會恢復所有內容。
- **另存為**：
  - DXF；
  - SVG（在 Inkscape 中圖層作為圖層開啟）；
  - .cnc2d 專案。
- **匯出**：
  - 1:1 比例的 PDF（用於列印模板）；
  - 可選解析度的 PNG 或 JPG；PNG 可為透明背景。
- **匯入向量**：從另一個 DXF、SVG 或 G 程式碼向當前模型新增向量。
- 舊 Windows-1251 編碼的 DXF（來自 ArtCAM/AutoCAD 的西里爾文字）可正確開啟。

## 14. 圖層

**專案** 標籤 → 圖層，或 **編輯 → 圖層…**：
- 新增圖層；
- 重新命名 ✎；
- 顏色；
- 顯示或隱藏 👁；
- 鎖定 🔒；
- 刪除 ✕。

新向量進入 **當前**（高亮）圖層。“移動” 把選中的向量移到當前圖層。

## 15. 撤銷與 “返回” 按鈕

- **撤銷／重做**：最多 80 步。
- 系統 **返回** 按鈕依次：
  1. 取消取點；
  2. 關閉開啟的工具；
  3. 關閉對話方塊；
  4. 返回開始介面（模型未儲存時會詢問）。

## 16. 匯入 G 程式碼（.tap、.nc）

應用可以開啟現成的機床程式（.tap、.nc、.ngc、.gcode 等）並從中恢復圖紙。
- 開啟檔案：開始介面上的 **開啟模型**（新模型），或 **檔案 → 匯入向量…**（新增到當前模型）。
- **刀具補償**：程式中記錄的是刀具中心軌跡。
  - “無” — 向量沿刀具中心（適合雕刻和沿向量加工）；
  - “自動” — 零件向內、孔向外偏移一個刀具半徑；
  - “全部向內”／“全部向外”。輸入刀具直徑。
- **合併分層加工** — 不同深度的多次走刀合併為一個輪廓。
- **每把刀具單獨一層** — 程式中有多把刀具時生成圖層 T1、T2…。
- 然後儲存圖紙：**檔案 → 儲存（DXF）**，可以編輯或計算新的刀具路徑。

## 17. 常見問題

- **刀具路徑無法計算：**
  - 外側／內側輪廓和區域清除需要 **封閉** 向量。請使用 “向量醫生” 或 “連線重合點”；
  - 刀具可能比槽更寬。
- **零件切在了錯誤的一側：** 檢查外側／內側設定和向量方向（“反轉方向”）。
- **切割鏤空時字母掉落：** 使用 “鏤空連線橋” 或輪廓中的連線橋。
- **機床位置 “偏移”：** 檢查模型原點（模型 → 原點位置）和材料設定中的原點位置。
- **小向量難以選中：** 用雙指放大，或使用從右到左的選擇框。
