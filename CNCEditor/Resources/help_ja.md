# CNC Editor 2D — ユーザーガイド

CNCルーター用の2D加工データを作るアプリです。ベクトルを描くか開き、工具パスを計算して、機械用のNCプログラムを保存します。
- **Weihong / NcStudio**：**.tap** ファイル、1スピンドル。
- **Superstar（4スピンドル）**：**.nc** ファイル。工具番号＝スピンドル番号。

## 1. はじめに

### スタート画面
- **新規モデル作成**：シートのサイズを設定します。
- **モデルを開く**：DXF、SVG、Gコード（.tap / .nc）、または .cnc2d プロジェクト。
- **画像・写真からモデル**：カメラ写真やギャラリー画像を下絵にします。
- **モデルに戻る**：モデルが開いているときに表示されます。
- 上部に **言語** の選択（🌐、17言語）。下部に **ユーザーガイド**、**プレミアム**、ARESTI Labs の他のアプリとウェブサイトへのリンク。

### 新規モデルのサイズ
- **幅（X）** と **高さ（Y）**：材料のサイズ。1830×2750、2070×2800、1220×2440、2050×3050 のボタンで標準サイズを入力できます。
- **原点**：図の角または中心をタップします。これが機械の X0 Y0 です。通常は左下の角。
- **単位**：mm またはインチ。内部ではすべてミリメートルで保存されます。
- **材料の厚さ**：工具パスの深さに使われます。

## 2. エディター画面

- **メニューバー**（上部）：🏠 スタート画面へ戻る、ファイル、編集、モデル、ベクトル、工具パス、ヘルプ。▸ の付いた項目はサブメニューを開き、「← 戻る」で戻ります。
- **表示バー**（メニューの下）：
  - ☰ — 左パネルの表示／非表示；
  - モデル全体表示、拡大、縮小、グリッド；
  - 元に戻す、やり直し；
  - **選択**、**ノード**、**選択に追加**；
  - ⟳ 画面の向き：横 → 縦 → 自動回転；
  - **選択 ▾** メニュー、⋮ 操作メニュー；
  - 「選択数：N」カウンター。
- **パネル**（3つのタブ、縦画面では下、横画面では左）：
  - **プロジェクト**：情報、レイヤー、選択のヒント、下絵；
  - **アシスタント**：描画と編集のすべてのツール。ツールを開くと、その入力欄がここに表示されます；
  - **工具パス**：工具パス一覧、材料、工具データベース、計算とNC保存。
- **シート**：白い長方形が材料です。原点の赤と緑の線は X 軸と Y 軸です。
- シート下部の **ヒント** が次にすることを示します。点の指定が必要なときは「キャンセル」ボタンがあります。

アイコンを長押しすると名前が表示されます。角に ◢ のあるアイコンはグループで、タップするとツール一覧が開きます。最後に選んだツールがボタンに残ります。

## 3. シート上のジェスチャー

- **ベクトルを1本指でタップ**：選択。
- **選択したベクトルをドラッグ**：移動。
- **枠の角の四角いハンドル**：比率を保った拡大縮小。
- **枠の上の丸いハンドル**：1°刻みの回転。
- **空いている所でドラッグ**：選択枠。
  - **左から右**（青の実線）：枠内に完全に入るベクトルを選択。
  - **右から左**（緑の破線）：枠に触れるすべてのベクトルを選択。
- **空いている所をタップ**：選択解除。
- **2本指**：移動とズーム（ピンチ）。
- **ベクトルを長押し**：複数選択モードがオンになります。
  - 以降のタップでベクトルを選択に追加または削除します。
  - ピンクの丸の数字は選択順です。順番は重要です：整列は最後に選んだものを基準にし、差は最後のものを引きます。
- **選択中に空いている所を長押し**：操作メニューを開きます。

選択されたベクトルは、光彩付きの太いピンクの線で描かれ、閉じた形は薄く塗りつぶされます。

## 4. 複数のベクトルを選ぶ（Shift キーの代わり）

- 表示バーの **選択に追加** ボタン：オンの間はタップごとにベクトルを追加／削除します。選択枠も既存の選択に追加されます。
- **ベクトルの長押し** で同じモードが一時的にオンになります。「選択に追加」または「選択解除」でオフにします。
- **選択 ▾** メニュー：
  - すべて；
  - 現在のレイヤーのすべて；
  - 閉じたものだけ、開いたものだけ；
  - 同じサイズ（最初に選んだ見本と同様）；
  - 選択の反転；
  - 選択解除；
  - 選択リスト。
- **選択リスト**（または「選択数：N」をタップ）：選択順のベクトルとサイズ。✕ で選択から外します。

## 5. 図形を描く

**アシスタント** タブ →「ベクトルツール」。どの図形も2通りで描けます：
- **指で**：シート上をドラッグ。パネルの欄にすぐサイズが表示されます。
- **数値で**：中心、幅、高さ、半径などを入力し「作成／完了」を押します。

描いたばかりの図形は、欄の値を変えるとシート上でも変わります。「完了」で確定します。「タップで中心」で中心をタップで指定できます。

- **長方形**：幅、高さ、角の半径。角は丸めまたは逆丸め（凹）。
- **円**：中心と半径または直径。
- **楕円**：中心、幅、高さ、回転角。
- **多角形**：辺の数、半径、回転。
- **星**：頂点の数、外側と内側の半径。
- **円弧**（3通り）：3点；中心・始点・終点；始点・終点・半径。
- **ポリライン**：シートをタップするたびに点が追加されます。次の点は数値でも入力可。「閉じる」で最初の点につなぎます。

**完成した図形を編集** するには：選択して ⋮ →「図形／テキストを編集…」。

## 6. ノード

**ノード** ボタン：ベクトルを選択して点をドラッグします。
- 青い四角は点、緑は始点、丸はベジェ制御点です。
- **点を長押し**：点の削除、スムーズ、始点にする、座標入力。
- **線分を長押し**：
  - 直線、円弧、ベジェ曲線に変換；
  - 点を挿入；
  - 始点を挿入；
  - 線分を削除（ベクトルを切る）。

## 7. ベクトルの編集

すべてのコマンドは **ベクトル** メニューと、アシスタントの「位置・結合・トリム」にあります。
- **変形**：正確な移動、サイズ（比率維持）、回転、傾斜。コピーあり／なし。
- **ミラー**：水平または垂直。自身の中心またはシート基準。
- **オフセット**：指定距離で外側または内側へ。角は鋭角または丸め。
- **ブロックコピー**：行と列、間隔またはピッチ指定。**円形**：中心の周りに N 個。
- **整列**：最後に選んだものを基準に端や中心で揃える。「シート中央」は材料基準。
- **グループ化／解除**：グループは一体で選択・移動されます。
- **閉じたベクトルの結合**：
  - 合体（足し算）；
  - 交差；
  - 差（最後に選んだものを他から引く）；
  - 共通部分の除外。
- **閉じる**：直線、曲線、または端点の移動で。**2本の開いたベクトルをつなぐ**：直線、曲線、端点の移動で。**一致点**：許容差内で多数の断片をチェーンにつなぎます。
- **ベクトルドクター**：一致点、自己交差、ループを見つけて修正します。
- **曲線を円弧に**：ベジェ曲線を円弧と直線に置き換えます（NCの行が減り、切削が滑らかに）。
- **フィレット**：角をタップして半径を設定。2本のベクトルを交点まで延長する機能もあります。
- **はさみ（トリム）**：線分をタップすると交点間の部分を削除します。
- **クリッピング**：選択した輪郭の内側または外側のベクトルを残します。
- **スライス**：X または Y 方向の線でベクトルを切断。
- **周囲の枠**：選択範囲の周りに余白付きの長方形。
- **変換**：ベクトルの中から円や長方形を見つけて「図形」にします。
- **方向の反転**：加工順と加工側に重要です。
- **ロック**：誤って動かせないようにします。
- **プロパティ**：サイズ、長さ、面積、点・直線・円弧・曲線の数。

## 8. テキスト

**ベクトルテキスト**：
- フォント：Arial 風、Times 風、Courier 風、DejaVu、または単線（1本線彫刻用）；
- 高さ、太字、斜体；
- 配置、文字間・行間、カーニング；
- 伸縮、傾き、回転；
- X/Y 位置。

「作成」でシートに追加されます。後で選択して ⋮ →「図形／テキストを編集」で編集できます。

**曲線上のテキスト**：曲線または円を選び「曲線上のテキスト」を開き、曲線上の開始位置、曲線からの距離、側を設定します。文字は曲線に沿って回転します。

## 9. エンベロープと「曲線に沿って貼り付け」

- **エンベロープ**：図柄を選んで「エンベロープ」を開くと、周りにノード付きの枠が現れます。角と辺の中点をドラッグします。または「上の曲線…」／「下の曲線…」を押して既存の曲線（例：円弧）をタップすると、枠がその形に沿います。「適用」で図柄が変形します。アーチや波などに模様を収められます。
- **曲線に沿って貼り付け**：選択した図柄のコピーを曲線に沿って均等に配置します。個数またはピッチ指定、曲線に沿って回転するかどうかを選べます。

## 10. プレートとネスティング

- **マルチプレート**：プレートのテンプレート（輪郭＋テキスト）をシート上に繰り返し、テキストファイルの各行を差し込みます。例：部屋番号や名前。1行＝1枚。
- **ネスティング**：選択した部品を、指定サイズのシートに間隔と端の余白をとって配置します。回転も許可できます。穴は自動的に部品と一緒に移動します。

## 11. 画像と写真

- **ファイル → 画像／写真を読み込む** または「画像」アイコン。ソースは **ギャラリー** または **カメラ**。画像は半透明の **下絵** になります。
- **下絵の設定**：不透明度、表示、ロック。サイズは数値または **2点指定** で：距離がわかっている2点をタップし、実際の距離を入力します。
- **手動トレース**：下絵の上にポリラインや図形で描きます。
- **ベクトル化**（「ベクトル化」アイコン）：
  1. モードを選ぶ：白黒（しきい値によるシルエット）または輪郭。
  2. 明るさのしきい値（または「自動」）、スムージング、ゴミ除去、反転を設定。
  3. 「プレビュー」で画像の上に完成予定のベクトルを表示。
  4. 「ベクトルを作成」でモデルに追加。
- **遠近補正**：斜めから撮影したシートは、写真の4隅をタップして実寸を入力すると、まっすぐな1:1の写真になります。
- **ステンシルブリッジ**：文字や図形の内側部分が落ちないようにする小さなつなぎ。

## 12. 工具パス（加工）

手順：
1. **材料**（工具パスタブ → 材料アイコン）：厚さ、安全高さ Z、ホーム位置（終了時に機械が移動する点）。
2. **工具データベース**：番号、直径、角度（V ビット用）、切り込み深さとステップオーバー、主軸回転数、送り速度、突っ込み速度。送りは mm/秒 または mm/分。工具の追加・複製・編集・削除ができ、データベースは端末に保存されます。
3. シート上で **ベクトルを選択** し、加工の種類を押します。

### 加工の種類
- **輪郭加工**：輪郭の外側または内側（工具半径を考慮）、または線上を切削。設定：
  - 開始と最終深さ；
  - 取り代；
  - 方向（ダウンカットまたはアップカット）；
  - 加工順。
- **タブ（ブリッジ）**：切削中に部品が外れないようにします。自動（個数または間隔）または輪郭上をタップして手動で配置。長さと高さを設定。
- **斜め突入（ランプ）**：工具を垂直ではなく斜めに材料へ入れます。負荷と跡が減ります。
- **ベクトルに沿った加工**：工具が線の上をそのまま進みます。彫刻、溝、単線文字に。
- **ポケット加工**：輪郭内部を削ります。オフセット（輪郭に沿う）またはラスター（ジグザグ）、重なり量を指定。
- **V 彫り**：V ビットで、線の幅に応じて深さが変わり「彫刻風」の文字や模様になります。
- **穴あけ**：円の中心に穴。ペック加工（ステップ指定）あり。

「工具」欄の **選択…** でデータベースから工具を選びます。**計算** ボタンで工具パスが作られ、その下に切削長、突入回数、予想時間が表示されます。

工具パス一覧：
- タップで工具パスとそのベクトルを選択；
- チェック — 表示／非表示；
- 「編集…」— パラメーターを開く；
- 「再計算」— ベクトル変更後に；
- 「削除」。

### シミュレーション
「シミュレーション」アイコン：工具が材料を削る様子を上から表示。再生／一時停止、速度、「結果」（一度に全部）、「最初から」。タブ、内側の角、隙間の確認に便利です。

### NCプログラムの保存
**工具パス → 工具パスを名前を付けて保存…**：
1. 必要な工具パスにチェック。
2. ポストプロセッサーを選択：
   - **Weihong（.tap）**：NcStudio 用；
   - **Superstar（.nc）**：4 スピンドル。工具番号 1〜4＝スピンドル番号；
   - **独自の .con**：「独自の .con を読み込む…」— 機械のポストプロセッサーファイル（ArtCAM 形式）。記憶されます。
3. ファイル名を設定。「プレビュー」でプログラムの冒頭を表示。「保存」でフォルダーを選択（USB メモリや機械への転送用フォルダーなど）。

**無料版：** 1日に1本の加工プログラムを保存できます。**プレミアム**（買い切り、永久）で制限と広告がなくなります。

**ヒント：** 初回の切削前に機械の原点と Z を確認し、まず Z を上げた「空運転」で試してください。

## 13. 保存とエクスポート

- **保存（DXF）**：一般的な DXF R12 で、どの CAD/CAM でも開けます。内部にはプロジェクト全体（レイヤー、工具パス、工具、下絵）が見えない形で保存され、このアプリで開くとすべて復元されます。
- **名前を付けて保存**：
  - DXF；
  - SVG（Inkscape でレイヤーとして開きます）；
  - .cnc2d プロジェクト。
- **エクスポート**：
  - 1:1 の PDF（型紙の印刷用）；
  - 解像度を選べる PNG または JPG。PNG は背景を透明にできます。
- **ベクトルの読み込み**：別の DXF、SVG、Gコードから現在のモデルへベクトルを追加。
- 旧 Windows-1251 エンコーディングの DXF（ArtCAM/AutoCAD のキリル文字）も正しく開けます。

## 14. レイヤー

**プロジェクト** タブ → レイヤー、または **編集 → レイヤー…**：
- レイヤーを追加；
- 名前の変更 ✎；
- 色；
- 表示／非表示 👁；
- ロック 🔒；
- 削除 ✕。

新しいベクトルは **アクティブ**（強調表示）レイヤーに入ります。「移動」で選択したベクトルをアクティブレイヤーへ移します。

## 15. 元に戻すと「戻る」ボタン

- **元に戻す／やり直し**：最大80手順。
- システムの **戻る** ボタンは次の順で動作します：
  1. 点の指定をキャンセル；
  2. 開いているツールを閉じる；
  3. ダイアログを閉じる；
  4. スタート画面へ戻る（モデルが未保存なら確認）。

## 16. Gコードの読み込み（.tap、.nc）

完成した加工プログラム（.tap、.nc、.ngc、.gcode など）を開き、そこから図面を復元できます。
- ファイルを開く：スタート画面の **モデルを開く**（新しいモデル）または **ファイル → ベクトルを読み込む…**（現在のモデルに追加）。
- **工具径補正**：プログラムには工具中心の軌跡が記録されています。
  - 「なし」— 工具中心に沿ったベクトル（彫刻やベクトルに沿った加工に適切）；
  - 「自動」— 部品は内側へ、穴は外側へ工具半径分ずらします；
  - 「すべて内側」／「すべて外側」。工具径を入力します。
- **深さ方向のパスをまとめる** — 異なる深さの複数パスが1つの輪郭になります。
- **工具ごとに別レイヤー** — プログラムに複数の工具がある場合、T1、T2… のレイヤー。
- その後、図面を保存：**ファイル → 保存（DXF）**。編集したり、新しい工具パスを計算したりできます。

## 17. よくある質問

- **工具パスが計算されない：**
  - 外側／内側の輪郭加工とポケットには **閉じた** ベクトルが必要です。「ベクトルドクター」または「一致点をつなぐ」を使ってください；
  - 工具がポケットより太い可能性があります。
- **部品が反対側で切られる：** 外側／内側の設定とベクトルの方向（「方向の反転」）を確認してください。
- **ステンシルで文字が抜け落ちる：**「ステンシルブリッジ」または輪郭加工のタブを使ってください。
- **機械の位置が「ずれる」：** モデルの原点（モデル → 原点位置）と材料設定のホーム位置を確認してください。
- **小さなベクトルが選びにくい：** 2本指で拡大するか、右から左への選択枠を使ってください。
