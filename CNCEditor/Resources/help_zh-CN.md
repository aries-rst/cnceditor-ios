# CNC Editor 2D — 用户指南

用于为数控雕刻机准备二维加工任务的应用：绘制或打开矢量，计算刀具路径，并为你的机床保存加工程序。
- **Weihong / NcStudio**：**.tap** 文件，单主轴。
- **Superstar（4 主轴）**：**.nc** 文件。刀具号即主轴号。

## 1. 入门

### 开始界面
- **新建模型**：设置板材尺寸。
- **打开模型**：DXF、SVG、G 代码（.tap / .nc）或 .cnc2d 项目。
- **从图片／照片建模**：相机照片或相册图片作为底图。
- **返回模型**：已有打开的模型时显示。
- 顶部为 **语言** 选择（🌐，17 种语言）。下方为 **用户指南**、**高级版**，以及 ARESTI Labs 其他应用和网站的链接。

### 新模型尺寸
- **宽度（X）** 和 **高度（Y）**：毛坯尺寸。按钮 1830×2750、2070×2800、1220×2440、2050×3050 可填入标准板材。
- **模型原点**：点击示意图的某个角或中心。这就是机床的 X0 Y0，通常为左下角。
- **单位**：毫米或英寸。内部一律以毫米保存。
- **材料厚度**：用于刀具路径的深度。

## 2. 编辑界面

- **菜单栏**（顶部）：🏠 返回开始界面，然后是 文件、编辑、模型、矢量、刀具路径、帮助。带 ▸ 的项目打开子菜单，“← 返回” 回到上一级。
- **视图栏**（菜单下方）：
  - ☰ — 显示或隐藏左侧面板；
  - 缩放至模型、放大、缩小、网格；
  - 撤销、重做；
  - **选择**、**节点**、**添加到选择**；
  - ⟳ 屏幕方向：横屏 → 竖屏 → 自动旋转；
  - **选择 ▾** 菜单，⋮ 操作菜单；
  - “已选：N” 计数。
- **面板**有三个标签（竖屏在底部，横屏在左侧）：
  - **项目**：信息、图层、选择提示、底图；
  - **助手**：所有绘图和编辑工具。打开某个工具时，其参数显示在这里；
  - **刀具路径**：路径列表、材料、刀具库、计算和保存程序。
- **图纸**：白色矩形就是毛坯。原点处的红色和绿色短线是 X 轴和 Y 轴。
- 图纸底部的 **提示** 告诉你现在该做什么。需要取点时会有 “取消” 按钮。

长按任意图标可显示其名称。角上带 ◢ 的图标是一个工具组：点击会打开其中的工具列表。最后选用的工具会留在按钮上。

## 3. 图纸上的手势

- **单指点击矢量**：选中它。
- **拖动已选矢量**：移动。
- **选框角上的方形手柄**：等比缩放。
- **选框上方的圆形手柄**：以 1° 步进旋转。
- **在空白处拖动**：选择框。
  - **从左到右**（蓝色实线）：选中完全位于框内的矢量。
  - **从右到左**（绿色虚线）：选中与框接触的所有矢量。
- **点击空白处**：取消选择。
- **双指**：平移和缩放（捏合）。
- **长按矢量**：开启多选。
  - 之后每次点击都会把矢量加入或移出选择。
  - 粉色圆圈中的数字表示选择顺序。顺序很重要：对齐以最后选中的为基准，相减时减去最后一个。
- **有选中对象时长按空白处** 会打开操作菜单。

选中的矢量以带光晕的粗粉色线显示，封闭矢量还会被浅色填充。

## 4. 选择多个矢量（代替 Shift 键）

- 视图栏上的 **添加到选择** 按钮：开启时，每次点击都会添加或移除矢量。选择框也会添加到已有选择中。
- **长按矢量** 会临时开启同样的模式。用 “添加到选择” 或 “取消选择” 关闭。
- **选择 ▾** 菜单：
  - 全部；
  - 当前图层全部；
  - 仅封闭、仅开放；
  - 相似尺寸（与第一个选中的样本相似）；
  - 反向选择；
  - 取消选择；
  - 已选列表。
- **已选列表**（或点击 “已选：N”）：按顺序列出矢量及其尺寸。✕ 将矢量移出选择。

## 5. 绘制图形

**助手** 标签 → “矢量工具”。每种图形都有两种画法：
- **用手指**：在图纸上拖动。面板字段立即显示尺寸。
- **用数值**：输入中心、宽度、高度、半径等，然后按 “创建／完成”。

图形刚画好时，修改任何字段都会在图纸上同步改变。“完成” 确定图形。“点击定中心” 可以点击指定中心。

- **矩形**：宽度、高度、圆角半径；圆角或反圆角（内凹）。
- **圆**：中心和半径或直径。
- **椭圆**：中心、宽度、高度、旋转角。
- **多边形**：边数、半径、旋转。
- **星形**：角数、外半径和内半径。
- **圆弧**，三种方式：三点；中心、起点和终点；起点、终点和半径。
- **多段线**：点击图纸，每次点击添加一个点。下一个点也可以用数值输入。“闭合” 连接到第一个点。

要 **编辑已完成的图形**：选中它，然后 ⋮ → “编辑图形／文字…”。

## 6. 节点

**节点** 按钮：选中矢量并拖动它的点。
- 蓝色方块是点，绿色是起点，圆圈是贝塞尔控制点。
- **长按点**：删除点、平滑、设为起点、输入坐标。
- **长按线段**：
  - 转换为直线、圆弧或贝塞尔曲线；
  - 插入点；
  - 插入起点；
  - 删除线段（剪断矢量）。

## 7. 编辑矢量

所有命令都在 **矢量** 菜单和助手中的 “定位、合并、修剪” 部分。
- **变换**：精确移动、尺寸（保持比例）、旋转、倾斜，可带或不带复制。
- **镜像**：水平或垂直，相对自身中心或图纸。
- **偏移**：向外或向内偏移指定距离；尖角或圆角。
- **阵列复制**：按行列，指定间隙或间距。**环形**：围绕中心 N 个副本。
- **对齐**：相对最后选中的对象按边和中心对齐；“图纸中心” — 相对毛坯。
- **组合／取消组合**：组作为一个整体被选择和移动。
- **合并封闭矢量**：
  - 焊接（相加）；
  - 相交；
  - 相减（从其他对象中减去最后选中的）；
  - 排除公共部分。
- **闭合**：用直线、曲线或移动端点闭合。**连接两个开放矢量**：用直线、曲线或移动端点。**重合点**：在公差范围内把许多碎片连成链。
- **矢量医生**：查找重合点、自相交和环并修复。
- **曲线转圆弧**：用圆弧和直线替换贝塞尔曲线（程序行更少，切削更平滑）。
- **倒圆角**：点击一个角并设置半径。这里还可以把两个矢量延伸到交点。
- **剪刀（修剪）**：点击线段即删除它在交点之间的部分。
- **裁剪**：保留所选轮廓内部或外部的矢量。
- **切分**：用沿 X 或 Y 方向的直线切开矢量。
- **外框**：在所选对象周围生成带边距的矩形。
- **转换**：在矢量中识别圆或矩形并转为 “图形”。
- **反转方向**：对加工顺序和加工侧很重要。
- **锁定**：防止矢量被误移动。
- **属性**：尺寸、长度、面积、点数、直线、圆弧和曲线数量。

## 8. 文字

**矢量文字**：
- 字体：类 Arial、类 Times、类 Courier、DejaVu 或单线体（用于单线雕刻）；
- 高度、粗体、斜体；
- 对齐、字距和行距、字偶间距；
- 拉伸、倾斜、旋转；
- X/Y 位置。

“创建” 将文字添加到图纸。之后可以选中并通过 ⋮ → “编辑图形／文字” 修改。

**沿曲线文字**：选中一条曲线或圆，打开 “沿曲线文字”，设置在曲线上的起点、与曲线的距离和方向。字母会沿曲线转动。

## 9. 封套与 “沿曲线粘贴”

- **封套**：选中图案，打开 “封套”。图案周围出现带节点的框。拖动角点和边的中点；或者按 “上曲线…”／“下曲线…” 并点击已有曲线（如圆弧），让框贴合其形状。“应用” 使图案变形。这样可以把花纹放进拱形、波浪形等。
- **沿曲线粘贴**：所选图案的副本沿曲线均匀分布 — 按数量或按步距，可选择是否沿曲线旋转。

## 10. 铭牌与排料

- **批量铭牌**：铭牌模板（轮廓 + 文字）在图纸上重复，并依次替换文本文件中的各行。例如门牌号或姓名：一行 — 一块铭牌。
- **排料**：所选零件按设定尺寸排放到板材上，带间隙和边距。可允许旋转。孔会自动跟随所属零件。

## 11. 图片和照片

- **文件 → 导入图片／照片** 菜单或 “图片” 图标。来源 — **相册** 或 **相机**。图片成为半透明的 **底图**。
- **底图设置**：不透明度、可见性、锁定。尺寸可用数值设置，或 **通过两点**：点击两个已知距离的点并输入实际距离。
- **手动描图**：在底图上用多段线和图形绘制。
- **矢量化**（“矢量化” 图标）：
  1. 选择模式：黑白（按阈值得到剪影）或轮廓。
  2. 设置亮度阈值（或 “自动”）、平滑、去除杂点、反相。
  3. “预览” 在图片上显示将要生成的矢量。
  4. “创建矢量” 将其加入模型。
- **透视校正**：如果板材是斜着拍的，点击照片上的四个角并输入实际尺寸，照片就会变正并成为 1:1 比例。
- **镂空连接桥**：小连接，使字母和图形的内部部分不会掉落。

## 12. 刀具路径（加工）

流程：
1. **材料**（刀具路径标签 → 材料图标）：厚度、安全高度 Z、原点位置（加工结束时机床返回的点）。
2. **刀具库**：刀具编号、直径、角度（V 形刀）、切深和步距、主轴转速、进给速度和下刀速度。进给单位为 mm/s 或 mm/min。可以添加、复制、编辑和删除刀具；刀具库保存在手机上。
3. 在图纸上 **选择矢量**，然后按加工类型。

### 加工类型
- **轮廓**：在轮廓外侧或内侧（考虑刀具半径）或沿线切割。设置：
  - 起始和最终深度；
  - 余量；
  - 方向（顺铣或逆铣）；
  - 加工顺序。
- **连接桥（Tabs）**：切割时零件不会脱落。自动放置（按数量或间距）或在轮廓上点击手动放置。可设置长度和高度。
- **斜坡下刀**：刀具倾斜进入材料而非垂直 — 负载更小、痕迹更少。
- **沿矢量加工**：刀具沿线正中行走。用于雕刻、开槽、单线文字。
- **区域清除**：轮廓内挖槽。偏移走刀（沿轮廓）或光栅（之字形），可设重叠量。
- **V 形雕刻**：使用 V 形刀，深度随线条宽度变化，形成 “雕刻感” 的文字和花纹。
- **钻孔**：在圆心处钻孔，支持啄钻（啄钻步距）。

在 “刀具” 部分按 **选择…** 从刀具库选择刀具。按 **计算** 生成刀具路径，下方显示切削长度、下刀次数和预计时间。

刀具路径列表：
- 点击选中路径及其矢量；
- 勾选 — 显示或隐藏；
- “编辑…” — 打开参数；
- “重新计算” — 修改矢量后使用；
- “删除”。

### 模拟
“模拟” 图标：俯视显示刀具在材料中的走刀过程。播放／暂停、速度、“结果”（一次显示全部）、“从头开始”。便于检查连接桥、内角和间隙。

### 保存加工程序
**刀具路径 → 刀具路径另存为…**：
1. 勾选需要的刀具路径。
2. 选择后处理器：
   - **Weihong（.tap）**：用于 NcStudio；
   - **Superstar（.nc）**：4 主轴；刀具号 1–4 = 主轴号；
   - **自定义 .con**：“加载自定义 .con…” — 你的机床后处理文件（ArtCAM 格式），会被记住。
3. 设置文件名。“预览” 显示程序开头。“保存” — 选择文件夹（例如 U 盘或用于传到机床的文件夹）。

**免费版：** 每天可保存 1 个加工程序。**高级版**（一次购买，永久有效）取消限制和广告。

**提示：** 第一次切割前，请在机床上检查零点和 Z。先抬高 Z “空走” 一遍程序。

## 13. 保存和导出

- **保存（DXF）**：标准 DXF R12，可在任何 CAD/CAM 程序中打开。其中隐藏保存了整个项目：图层、刀具路径、刀具、底图。在本应用中打开这样的 DXF 会恢复所有内容。
- **另存为**：
  - DXF；
  - SVG（在 Inkscape 中图层作为图层打开）；
  - .cnc2d 项目。
- **导出**：
  - 1:1 比例的 PDF（用于打印模板）；
  - 可选分辨率的 PNG 或 JPG；PNG 可为透明背景。
- **导入矢量**：从另一个 DXF、SVG 或 G 代码向当前模型添加矢量。
- 旧 Windows-1251 编码的 DXF（来自 ArtCAM/AutoCAD 的西里尔文字）可正确打开。

## 14. 图层

**项目** 标签 → 图层，或 **编辑 → 图层…**：
- 添加图层；
- 重命名 ✎；
- 颜色；
- 显示或隐藏 👁；
- 锁定 🔒；
- 删除 ✕。

新矢量进入 **当前**（高亮）图层。“移动” 把选中的矢量移到当前图层。

## 15. 撤销与 “返回” 按钮

- **撤销／重做**：最多 80 步。
- 系统 **返回** 按钮依次：
  1. 取消取点；
  2. 关闭打开的工具；
  3. 关闭对话框；
  4. 返回开始界面（模型未保存时会询问）。

## 16. 导入 G 代码（.tap、.nc）

应用可以打开现成的机床程序（.tap、.nc、.ngc、.gcode 等）并从中恢复图纸。
- 打开文件：开始界面上的 **打开模型**（新模型），或 **文件 → 导入矢量…**（添加到当前模型）。
- **刀具补偿**：程序中记录的是刀具中心轨迹。
  - “无” — 矢量沿刀具中心（适合雕刻和沿矢量加工）；
  - “自动” — 零件向内、孔向外偏移一个刀具半径；
  - “全部向内”／“全部向外”。输入刀具直径。
- **合并分层加工** — 不同深度的多次走刀合并为一个轮廓。
- **每把刀具单独一层** — 程序中有多把刀具时生成图层 T1、T2…。
- 然后保存图纸：**文件 → 保存（DXF）**，可以编辑或计算新的刀具路径。

## 17. 常见问题

- **刀具路径无法计算：**
  - 外侧／内侧轮廓和区域清除需要 **封闭** 矢量。请使用 “矢量医生” 或 “连接重合点”；
  - 刀具可能比槽更宽。
- **零件切在了错误的一侧：** 检查外侧／内侧设置和矢量方向（“反转方向”）。
- **切割镂空时字母掉落：** 使用 “镂空连接桥” 或轮廓中的连接桥。
- **机床位置 “偏移”：** 检查模型原点（模型 → 原点位置）和材料设置中的原点位置。
- **小矢量难以选中：** 用双指放大，或使用从右到左的选择框。
